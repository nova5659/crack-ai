# CRACK AI · 인터랙티브 캐릭터 챗 & 웹소설 스토리 플랫폼

뤼튼 **크랙(Crack)** 스타일의 몰입형 AI 캐릭터 챗 & 인터랙티브 웹소설 플랫폼입니다.
**macOS 네이티브 앱 (`CrackAI.app`) + 반응형 웹 사이트 + 모바일 Safari PWA**를 하나로 제공하며, Google AI Studio **무료 티어 최고 성능 모델 (`Gemini 3.8 Flash` + `Gemini 3.5 Flash-Lite`)**을 기본 탑재했습니다.

## 주요 기능

1. **Google Gemini 무료 티어 최강 API 연동**
   - 기본 추천 모델: **`gemini-3.8-flash`** (무료 티어 최고 성능 · 웹소설 문체 & 감정선 특화)
   - 초고속·대용량 보조 모델: **`gemini-3.5-flash-lite`** (추천 답변 3개 생성, 요약 메모리 자동 갱신, 스피드 모드)
   - **자동 폴백 체인**: 한 모델의 일일/분당 무료 한도(429)에 도달하면 `gemini-3.8-flash → gemini-3.5-flash → gemini-3.5-flash-lite → gemini-3-flash-preview → gemini-2.5-flash` 순으로 끊김 없이 자동 전환
   - **API 키 없이도 즉시 체험**: 키를 넣기 전에도 내장 미리보기 엔진으로 모든 UI/스토리 기능을 체험할 수 있으며, 상단 **[🔑 무료 Gemini API]** 버튼에서 Google AI Studio 무료 키(카드 등록 불필요)를 입력하면 즉시 실제 Gemini AI가 연결됩니다.

2. **방대한 메이저 애니메이션 아카이브 (39개 작품 · 41종 애니 월드 + AI 무한 소환기)**
   - **전용 `🎬 애니 월드` 허브**: 주술회전, 귀멸의 칼날, 원피스, 나루토, 블리치, 드래곤볼, 헌터×헌터, 나의 히어로 아카데미아, 체인소 맨, 원펀맨, 죠죠의 기묘한 모험, 장송의 프리렌, 나 혼자만 레벨업, 소드 아트 온라인, 리제로, 강철의 연금술사, 오버로드, 약사의 혼잣말, 진격의 거인, 데스노트, 명탐정 코난, 코드 기아스, 에반게리온, 사이버펑크: 엣지러너, 최애의 아이, 스파이 패밀리, 블루 록, 하이큐!!, 은혼, 봇치 더 록!, 단다단, 슬램덩크, 도쿄 구울, 슈타인즈 게이트, 카구야 님은 고백받고 싶어, 모브사이코 100, 바이올렛 에버가든, 사카모토 데이즈, 포켓몬스터까지!
   - **2가지 플레이 방식**: `👤 1:1 인기 캐릭터 챗` + `🌍 멀티 캐릭터 세계관 RPG 시뮬레이션` (각 애니 고유 파워 시스템·상태창 지원)
   - **⚡ AI 애니 무한 소환기**: 목록에 없는 애니메이션도 작품명만 입력하면 5초 만에 원작 고증 캐릭터·세계관·로어북·오프닝을 자동 생성해 바로 플레이!
   - **📚 원작 고증(CANON) ↔ ✨ IF 자유 전개(WHAT-IF)** 실시간 전환 (원작 비극을 막는 생존 IF 루트 지원)

3. **크랙(Crack) 핵심 UX 완벽 구현**
   - **오리지널 캐릭터 8종 + 메이저 애니 41종 (총 49종 기본 탑재)** (로맨스, 로판/회귀, 무협, 현대/일상, 사이버펑크, 추리/스릴러, 이세계 RPG 시뮬레이션, 연예계, 애니메이션)
   - **소설형 UI ↔ 채팅형 UI 실시간 전환** & 고딕/명조 웹소설 글꼴 전환 (`*지문*`, `"대사"`, `**[상태창]**` 전용 렌더링)
   - **추천 답변 (💡) 토글 트레이**: 상황에 맞는 3가지 선택지 자동 생성 → 클릭 시 입력창에 채워져 수정 후 전송 가능
   - **유저노트 (최대 2,000자)** · **AI 요약 메모리** · **로어북(키워드북) 실시간 발동 배지**
   - **실시간 호감도 & 감정 상태창 (HUD)**: 대화 흐름에 따라 캐릭터 감정과 호감도 게이지가 실시간 반응
   - **파워 유저 도구**: 실시간 스트리밍 중지, 답변 재생성 & 버전 스와이프(`1 / 2`), 이어쓰기, 메시지 수정, 특정 턴으로 되돌리기(분기), 멀티 회차 관리, 웹소설(`.md`) 내보내기
   - **캐릭터 스튜디오 (제작 공간)**: 이미지 업로드, **AI 한 줄 아이디어 자동 완성**, 로어북 에디터, JSON 카드 내보내기/불러오기

4. **macOS 앱 + 24시간 상시 클라우드 웹 사이트 + 모바일 PWA**
   - **24시간 상시 클라우드 웹 (Mac 꺼져도 항시 접속)**:
     - [netlify.toml](netlify.toml) + [netlify/functions/gemini.mjs](netlify/functions/gemini.mjs) + [web/data/catalog.json](web/data/catalog.json) + [web/sw.js](web/sw.js) 완비!
     - **Netlify Functions 스트리밍 프록시** + **브라우저 로컬 저장 + 전체 JSON 백업/복원** + **순수 정적 호스팅(CORS 직접 연결) 자동 폴백**까지 지원합니다.
     - Netlify 환경변수에 `GEMINI_API_KEY`를 한 번만 등록하면 스마트폰/PC 어디서 열어도 API 키 재입력 없이 24시간 바로 AI 대화가 가능합니다.
   - **macOS 네이티브 앱**: `CrackAI.app` 더블클릭으로 바로 실행 (상단 메뉴바 `✦` 상주)
   - **아이폰/모바일 앱 설치**: 배포된 `https://...netlify.app` 주소를 모바일 Safari에서 열고 **공유 → 홈 화면에 추가**

## 실행 · 배포 · 테스트

```bash
# 1. 자동 테스트 실행 (10개 테스트)
npm test

# 2. 정적 클라우드 웹 카탈로그 빌드 (49개 월드 → web/data/catalog.json)
npm run build:web

# 3. 24시간 상시 클라우드 웹(Netlify) 영구 배포
npm run deploy:netlify

# 4. 로컬 웹 사이트 서버 실행
npm start

# 5. macOS 네이티브 앱(.app) 재빌드
npm run build:app
```
